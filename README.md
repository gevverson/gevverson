### 🚀 Featured work

**[FraudGuard AI](https://github.com/gevverson/fraudguard-ai)**: explainable, multi-tenant fraud-decisioning API for card, mobile-money and payout metadata (advisory shadow pilot).
- PostgreSQL ledger with tenant-scoped idempotency, exact response replay, append-only audit events and a transactional outbox; row-level security tested in CI against real Postgres
- Redis Lua sliding-window velocity and a distributed token-bucket quota; fails closed when shared state is unavailable
- Opaque API keys stored only as HMAC digests, with zero-downtime rotation; versioned, rollback-able tenant policies
- Python · FastAPI · PostgreSQL · Redis · Prometheus · Docker Compose · GitHub Actions

**[Macho ya Mwananchi](https://github.com/gevverson/aldai-hub)**: civic-accountability platform that turns Kenya's Auditor-General reports into searchable project and finding data ([live site](https://macho-ya-mwananchi-client.onrender.com)).
- 47 counties, 1,449 projects and 8,551 audit findings from 46 official audit PDFs
- RAG question-answering over the source documents in English and Swahili, plus GPS-based citizen verification
- React/Vite · Node/Express · FastAPI · MongoDB · ChromaDB · Gemini · Docker · end-to-end tests in GitHub Actions

**Helix** ([mobile app](https://github.com/gevverson/helix_mobile)): genetic-compatibility platform that keeps genotype data encrypted and returns a sickle-cell / rhesus compatibility verdict (educational, not diagnostic).
- FastAPI + PostgreSQL backend (private repo): 27 endpoints, 13 Alembic migrations, ~150 tests, field-level encryption, right-to-erasure cascade
- Flutter client: go_router auth guards, Provider state, OCR import of lab reports, Google Sign-In with silent session refresh

**[AI Trading Engine](https://github.com/gevverson/ai-trading-bot)**: self-hosted research and paper-trading stack.
- FastAPI backend, TimescaleDB tick storage, Redis, ChromaDB news memory, MT5 bridge, React dashboard, all in Docker Compose
- HMM regime detection, Kalman filtering, Bayesian trade scoring, ATR-based volatility and Kelly position sizing
